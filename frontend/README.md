# MotorDoctor.in - Frontend Application

Modern React 18 + TypeScript + Vite + Tailwind CSS + Radix UI platform for independent automobile service bill audits.

## 🚀 How to Run Frontend

```bash
cd frontend
npm install
npm run dev
```

App runs at: `http://localhost:8080`

## 🛠 Features

- **Hero & On-Page Auth:** Instant Register & Sign In forms directly on the hero with GPS auto-detection.
- **Scam & Savings Calculator:** Interactive detector for dealership rip-offs (engine flush, AC sprays, caliper greasing).
- **Multi-Step Bill Upload:** 4-step consultation booking flow with instant Ticket ID.
- **Real-Time Visitor Location Tracking:** Live GPS coordinates and OpenStreetMap / Google Maps surveillance.
